# Агресивний мобільний лендинг
Перший екран: товар, знижка, ціна, таймер, CTA. Форма нижче по скролу.

## Редагування
- `config.js`: тексти, ціни, фотографії, блоки та дата завершення акції.
- `style.css`: кольори, рамки, скруглення у `:root`.
- `images/`: ваші фото. SVG зараз — ілюстративна заглушка.
- Не використовуйте вигадані відгуки або фіктивний таймер.
- На дуже низьких екранах браузер може вимагати невеликого скролу; ключова пропозиція має пріоритет.

## Публікація
Завантажте папку на GitHub, імпортуйте репозиторій у Vercel.
У Vercel → Settings → Environment Variables додайте:
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ALLOWED_ORIGINS` (наприклад `https://your-project.vercel.app`),
`PRODUCT_NAME`, `PRODUCT_PRICE`. Зробіть Redeploy.
Бот: створіть через @BotFather, напишіть йому /start, отримайте chat_id через getUpdates.
Токен не публікуйте в GitHub. На GitHub Pages API не працює без окремого серверного хостингу.
Для реального рекламного трафіку додайте Turnstile, серверний rate limit та політику конфіденційності.

## Блоки опису товару
FAQ видалено. У `config.js` редагуйте `description`, `specs`, `usage`; керуйте видимістю через `sections`.
Використано фото товару, надане в розмові. Перевірте права на публікацію фото.
Характеристики звірені зі сторінкою постачальника websklad.biz.ua, артикул ws82511.
Вказані ціни 1299/649 грн — демонстраційна пропозиція з попереднього макета, а не підтверджена ціна постачальника.
Рекламний заголовок про 5 хвилин — маркетинговий приклад, а не гарантований час укладання.

## Логотип магазину
У шапці використано адаптивний inline SVG: змінюйте `--accent` у `style.css`, колір кошика та `.shop` зміниться автоматично.
Назва у `config.js`: `brand` і `brandDomain`.
Окремий файл `images/bestyshop-logo.svg` можна використовувати для інших задач. У standalone SVG змінюйте `--accent` безпосередньо в його стилях.

## Ширша шапка
Повернуто оригінальну B з кошиком. На екранах до 699 px прибрано напис про доставку з шапки, розширено місце для назви магазину, іконку зроблено компактною.
Зміни тільки в `style.css`, інші файли залишаються без змін.

## Кольори логотипу та знижка
- `--logo-accent: var(--accent)` у `style.css`: змінює тільки корзину та `.shop` у шапці.
- Буква B і `bestyshop` завжди білі.
- Бейдж −50% на фото прибрано; він залишився біля ціни.
- Для оновлення існуючого сайту замініть `index.html`, `style.css`, `script.js`.
